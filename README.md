# Tugas 1 - Website Development

## Deskripsi

Proyek ini merupakan tugas dasar pengembangan website dalam pembelajaran Pengembangan Perangkat Lunak dan Gim (PPLG).

## Tujuan

* Mengenal struktur dasar halaman website menggunakan HTML.
* Mempelajari cara mengatur tampilan website menggunakan CSS.
* Memahami pengelolaan file proyek melalui GitHub.

## Teknologi yang Digunakan

* HTML
* CSS
* GitHub

## Struktur File

* `index.html` — berisi struktur dan konten halaman website.
* `style.css` — berisi pengaturan tampilan dan desain website.

## Kesimpulan

Melalui tugas ini, saya belajar membuat halaman website sederhana menggunakan HTML dan CSS serta menyimpan proyek di GitHub.
